# HAMLET Visual Direction — Contemporary African Hospitality

This document records the approved visual direction for the current brand refresh.

## Brand personality
HAMLET should feel like a Nigerian hospitality brand with global product standards: warm, confident, locally grounded, editorial and commercially trustworthy. Avoid generic marketplace and generic SaaS-dashboard styling.

## Core visual system
- Warm ivory canvas: #F7F4ED
- Deep forest green: #173F32
- Charcoal: #252923
- Muted brass: #B58A52
- Terracotta: #BD765C
- Soft stone: #E8E6DD
- Editorial headings: Playfair Display / Newsreader family
- Functional body: Inter / DM Sans family

Use brass as a restrained highlight, not for long body text. Use forest green for primary actions and key brand surfaces. Keep semantic status colours distinct from decorative brand accents.

## Experience principles
### Guest marketplace
- Tell the Lagos story through real neighbourhoods, architecture and property imagery.
- Make Island/Mainland discovery legible and useful.
- Give Nigerian stay essentials (power arrangements, water, internet, access, security and parking) visible, factual treatment where listing data supports it.
- Keep availability, pricing and verification grounded in live records.
- Do not add invented ratings, review counts, prices or claims.

### Property detail
- Prioritise photography, property facts, amenities, location context, house rules and transparent booking stages.
- Show exactly which verification checks have been completed; never imply blanket certification from a partial check.
- Preserve request-based booking and the existing payment sequence.

### Owner workspace
- Focus on property operations: submissions, review state, bookings, availability, earnings and performance.
- Use clear information hierarchy and useful data density rather than decorative KPI tiles.

### Partner workspace
- Treat partners as a distribution and supply network, not merely affiliates.
- Surface referrals, leads, property introductions, booking attribution and commission states.
- Explain what is estimated, pending, approved, payable and paid.

### Admin workspace
- Prioritise operational control, verification queues, booking integrity, financial reconciliation, disputes and auditability.
- Admin screens should be information-dense but calm and consistent.

## Implementation guardrails
- Preserve the current Next.js route structure, Supabase queries, role checks, RLS assumptions, central pricing logic, referral attribution and booking/payment workflows.
- Do not replace database-backed values with mock statistics.
- Do not introduce new commercial fees or commission percentages through design.
- Maintain accessibility, responsive behaviour, reduced-motion preferences and existing SEO metadata.
- Roll out visual changes incrementally and review every role journey at mobile and desktop widths.
